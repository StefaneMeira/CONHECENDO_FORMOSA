Conhecendo Formosa - GO

Olá! Este é o meu projeto final, onde decidi criar um guia especial sobre Formosa, em Goiás. A ideia principal foi unir informações sobre o turismo local com um visual moderno e fácil de usar.



Para construir o site, foquei bastante na organização do código. Usei o HTML para estruturar tudo de forma correta e o CSS para dar vida ao design. O maior desafio (e também o que eu mais gostei de fazer) foi trabalhar com o Flexbox para garantir que todos os formulários e textos ficassem perfeitamente alinhados e centralizados na tela, independentemente do tamanho do monitor.

Também dediquei um tempo especial aos detalhes visuais, como as cores azul e amarelo que representam bem a nossa região, e criei efeitos nos botões para que a navegação ficasse mais interativa e agradável para o usuário.


Trabalhei basicamente com as tecnologias fundamentais da web: HTML5 e CSS3. Também integrei fontes do Google Fonts (Montserrat e Roboto) para deixar a leitura mais leve e profissional.



Este trabalho foi muito importante para mim, pois pude colocar em prática conceitos como o modelo de caixa (box model), responsividade e a criação de formulários que não são apenas funcionais, mas também bonitos.

Desenvolvido com dedicação por Stéfane.
